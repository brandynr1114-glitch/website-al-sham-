# AL-SHAM Middle Eastern Food - Website

Landing page for AL-SHAM Restaurant, a Middle Eastern food chain with 10 locations in the Philadelphia area.

## Features

- Sticky navigation header with mobile hamburger menu
- Hero section with delivery ordering buttons (DoorDash, Uber Eats, in-store pickup)
- Floating social media sidebar (Facebook, Instagram)
- "Why AL-SHAM" feature cards with hover animations
- Menu highlights grid with image zoom effects
- Instagram-style food gallery with overlay effects
- Interactive locations section with single embedded map (click a location to update the map)
- Fully responsive for mobile, tablet, and desktop
- Scroll-reveal animations throughout
- CTA banner and full footer

## Tech Stack

- Single-file HTML/CSS/JS (no build step required)
- Google Fonts (Lobster + Nunito)
- Font Awesome 6 icons
- Google Maps Embed API

## Getting Started

Open `index.html` in any browser. No server or build tools required.
